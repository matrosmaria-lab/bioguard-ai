# 🛢️ BioGuard AI — Мониторинг и прогноз биокоррозии

Интеллектуальная система оценки риска биокоррозии на нефтепромысловом оборудовании на основе машинного обучения.

## 🚀 Функционал
- **Прогнозирование износа**: Оценка скорости коррозии в мм/год с помощью ML-модели (`RandomForestRegressor`).
- **Интерактивный дашборд**: Наглядная визуализация зависимости риска от активности сульфатредуцирующих бактерий (СРБ) и $H_2S$.
- **AI-рекомендации**: Автоматические предупреждения и советы по вводу бактерицидов для оператора.
- **Экспорт отчётов**: Выгрузка текущих параметров и прогнозов в формате CSV.
